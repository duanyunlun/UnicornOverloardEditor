# 网页样式检查

检查日期：2026-09-08。

## 修改边界

全站布局修改限于 `web/style.css` 和 `web/mission/src/App.css`；下拉选项精简修改 `SearchableCombobox.tsx` 的显示标记。不修改模块归属、数据、事件处理、补丁生成、导入导出或校验逻辑。

战术预设显示名由现有引用职业生成（例如“先锋 · 战术预设 #2”），无职业引用时优先使用已知技能名，否则显示预设编号。这是依据目录生成的摘要，不是内部代号的官方译名。列表、详情标题及任务中的预设选项使用同一规则；原始代号保留在列表和标题的悬停提示中，也可用于搜索。自定义预设名称、内部符号、ID 和导出数据不变。

右侧统一的“共享战术预设”说明框已移除。其规则仍为：非零预设使用战术表，装备技能须显式添加；预设为空时游戏中没有战术。引用关系和逐项条件编辑仍保留。

## 验证

使用 Microsoft Edge 的 Playwright 自动化，覆盖 8 个分类、17 个 MOD 子页、空存档入口和 5 个存档编辑页。测试组合为 1440×900 简体中文浅色、1024×768 英文浅色、390×844 简体中文浅色、1440×900 日文深色。

`web/browser-style-audit.mjs` 共输出 199 张截图，检查横向溢出、控件越界、下拉菜单边界、展开说明及长页面中段和底部，包含所有存档页的展开与底部状态；结果无发现、无页面错误。按钮内容纵向中心和居中命令按钮的横向中心容差为 2px，装备清空按钮相邻中心容差为 1px。正文及引用展开入口不按命令按钮强制居中。截图保存在忽略目录 `.tools/browser-validation/style-audit/`，并人工检查各类页面布局。

另通过 52 项核心测试、两个 Web 构建，以及 `browser-smoke.mjs`、`browser-locale-layout.mjs`、`browser-runtime.mjs` 三组回归，包含语言切换、编辑保留、独立滚动、工程保存和实际导出文件校验。

复现样式检查（先启动本地预览）：

```sh
AUDIT_STRICT=1 BROWSER_EXECUTABLE='/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge' TEST_URL=http://127.0.0.1:4181/ node web/browser-style-audit.mjs
```
