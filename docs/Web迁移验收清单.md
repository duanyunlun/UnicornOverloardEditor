## 可运行验证

`npm test --prefix web` 覆盖存档字段/备份、批量角色原子性、容量/ID 边界、两版 MOD 输出、任务预设/装备、工程兼容、冲突拒绝和三语名称。`npm run build --prefix web/mission`、`npm run build --prefix web` 验证完整纯 Web 构建。

`web/browser-smoke.mjs` 在浏览器真实选择两个角色文件、多选添加道具/装备（筛选后仍保留选择）、修改部队、下载存档并逐字节检查备份，同时检查八分类隔离、任务/装备页面、完整工程往返、MOD ZIP 与手机布局。`browser-locale-layout.mjs` 和 `browser-runtime.mjs` 继续覆盖多语言、独立滚动、亚洲运行时 ZIP 及源文件保护。

本次本地结果：51 项核心测试全部通过、无跳过；两层 Web 构建及三组浏览器脚本通过。旧桌面工程完成浏览器载入、转换后工程下载和 MOD ZIP 再导出；40 个迁移数据文件与迁移前提交逐字节一致，发布工作流 YAML 解析通过。桌面 App 不再构建测试；手动 Web Release 流程尚未实际创建新版本，日常发布使用 Pages。

## 边界

浏览器使用下载副本替代桌面的原路径写入，不自动安装存档/MOD，不依赖本地后端。文本/CPK 是唯一明确保留的迁移例外；若恢复该需求，必须另行完成浏览器 CPK 解析/重建验证，不能用只能导出 FMS 的界面冒充完整文本 MOD。

游戏内验证与功能迁移分开：亚洲 2 倍经验、动态等级及组合已完成样本对照，不能外推为所有倍率、例外关卡或全部模块均已实测。详见《亚洲版经验与等级补丁验证》。
